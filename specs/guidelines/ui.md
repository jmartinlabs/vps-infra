# UI guidelines

## Applicability
**No aplica.** `vps-infra` contiene documentación, contratos y scripts de plataforma; no
publica una interfaz gráfica propia. No se imponen direcciones visuales, tokens ni
viewport.

Las interfaces de las aplicaciones alojadas pertenecen a sus repositorios. Este
repositorio solo puede fijar contratos de despliegue no visuales (rutas, healthchecks,
puertos internos y variables no secretas).

Si en el futuro se añade un panel propio, se documentarán aquí dirección visual,
tokens, accesibilidad, estados y evidencia antes de implementarlo.
